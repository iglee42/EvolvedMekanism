# Evolved Mekanism APT Only

## 📖 Description

> A lightweight fork of Evolved Mekanism that keeps only APT, selected resources, alloys, and circuits for a more focused progression.
> This mod is designed for players who want to experience the core mechanics of APT without the complexity of the full EvolvedMekanism mod, while still enjoying a streamlined resource and alloy system.

## ✨ Features
- Removed everything except:
  - APT
  - Better Gold, Plaslitherite, Refined Redstone
  - Netherrack and End Stone Uranium Ore
  - Alloys and Alloy Blocks
  - Circuits
